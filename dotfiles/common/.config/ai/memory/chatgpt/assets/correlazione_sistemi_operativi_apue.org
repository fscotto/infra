* Nota
Questa tabella mette in relazione i capitoli di /Sistemi Operativi - Concetti ed esempi/, 8ª edizione, di Silberschatz, Galvin e Gagne, con i capitoli di /Advanced Programming in the UNIX Environment/ (APUE), 3ª edizione, di Stevens e Rago.

L'obiettivo non è sostituire nessuno dei due testi, ma usarli insieme:

- *Sistemi Operativi* fornisce il modello teorico: processi, memoria, file system, scheduling, sincronizzazione, I/O.
- *APUE* mostra come quei concetti emergono concretamente nelle API UNIX/POSIX.

* Lettura pratica consigliata

** Metodo
Per ogni argomento APUE, fai questo ciclo:

1. Leggi il capitolo APUE.
2. Torna al capitolo teorico corrispondente di /Sistemi Operativi/.
3. Scrivi un piccolo programma C che dimostri il comportamento.
4. Osserva con strumenti come =strace=, =lsof=, =ps=, =pstree=, =top=, =gdb=.

** Esempi concreti

| Tema | Teoria | APUE | Esperimento C |
|------+--------+------+---------------|
| =fork()= | Processi + memoria virtuale | APUE 8 | Modifica una variabile dopo =fork()= e osserva che padre e figlio non condividono lo stesso valore. |
| Buffering | I/O + file system implementation | APUE 5 | Usa =printf()= prima di =fork()= e confronta con =write()=. |
| File descriptor | File system + I/O | APUE 3-4 | Apri un file, fai =fork()=, scrivi da padre e figlio, osserva offset condiviso. |
| Zombie | Process lifecycle | APUE 8 | Crea un figlio che termina senza =wait()= e osserva con =ps=. |
| Pipe | IPC | APUE 15 | Implementa =ls | wc -l= con =pipe()=, =fork()=, =dup2()=, =execvp()=. |
| Signal safety | Sincronizzazione + interrupt | APUE 10 | Gestisci =SIGINT= usando =sigaction()= e solo funzioni async-signal-safe. |
| Thread race | Thread + sincronizzazione | APUE 11-12 | Incrementa un contatore condiviso con e senza mutex. |
| mmap | Memoria virtuale + I/O | APUE 14 | Mappa un file in memoria e modifica il contenuto tramite puntatore. |

1. Cap. 1 - Introduzione
2. Cap. 2 - Strutture dei sistemi operativi
3. Cap. 3 - Processi
4. Cap. 4 - Thread
5. Cap. 6 - Sincronizzazione dei processi
6. Cap. 8 - Memoria principale
7. Cap. 9 - Memoria virtuale
8. Cap. 10 - Interfaccia del file system
9. Cap. 11 - Implementazione del file system
10. Cap. 13 - Sistemi di I/O

Il resto è utile, ma può essere letto dopo o solo quando APUE porta naturalmente verso quei temi.
